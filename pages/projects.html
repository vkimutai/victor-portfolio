1. Manchester united recent form

In this mini-project, I practiced using the <iframe></iframe> which embeds an external video onto our website inside a frame

The iframe element has multiple attributes some being:

accelerometer
Allows motion sensor data (used on mobile devices)
autoplay
Allows the video to start automatically.
clipboard-write
Allows writing to the clipboard (copy feature).

2. Building audio and video player

In this project I was trying to add video and audio player in my website

                
                   <video width="640" controls>
                        <source src="https://cdn.freecodecamp.org/curriculum/labs/what-is-the-map-method-and-how-does-it-work.mp4" type="video/mp4">
                    >/video>

This line of code add a video in our website

other attributes to add to the <video> element is controls which add the controls buttons in the video player, autoplay which plays the video when viewed on the screen and lastly but not least the muted which autoplay video in muted state
